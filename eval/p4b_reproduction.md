## Silent-cause mechanism (diagnosis only)

| Seed | change_based (rank / top-1) | graph_rwr (rank / top-1) | trace_ochiai (rank / top-1) | temporal_lag (rank / top-1) | ensemble (rank / top-1) |
|---:|---|---|---|---|---|
| 1 | absent / none | 1 / database | 2 / inventory | absent / payments | 3 / inventory |
| 2 | absent / none | 1 / database | 2 / checkout | absent / inventory | 3 / inventory |
| 3 | absent / none | 1 / database | 1 / database | absent / inventory | 3 / inventory |

The miss is reciprocal-rank vote mass, not a cutoff or tie: graph_rwr ranks database first in all cases; trace_ochiai ranks it second in two and first in one. However, temporal_lag returns no database candidate and ranks payments or inventory first; trace_ochiai's non-database first choices also add rank mass ahead of database. Change-based emits no candidates. The ensemble order is inventory, payments, database, checkout in all three cases. No threshold is involved in rank fusion, and the strict ordering rules out tie-breaking. Evidence-based abstention cannot help when competing candidates have valid evidence from their own methods. P5 design should therefore target evidence-weighted contribution or a decisive margin/abstention at the ensemble level; it risks suppressing genuine shared-root findings where one method alone has the strongest valid signal.

## Recommended P5 directions (ranked; proposal only)

1. Calibrate/redefine “verified” as a separately tested evidential standard, since current rules yield 0 true verified cases.
2. Investigate fusion rank dilution and confidence/margin abstention using new development-only tests; risk is losing shared-root findings supported by one method.
3. Rework graph-based alternative evidence so shared ancestry alone cannot support a causal decoy.
4. Add future scenarios for alert noise with realistic ordering, incomplete traces/graphs, and simultaneous independent causes. Do not use holdout for design iterations.

Holdout run is not recommended yet: current “verified” has zero true confirmations and major evidence semantics remain under design. Recommend first fixing those under a separately approved phase, then request a single final holdout run only after the protocol is frozen.
